# MiniSQL
Un simple simulador de SQL hecho en python
---
MiniSQL es un experimento sencillo hecho en python para comprender mejor el backend de un SQL real.

> NOTA🚧: Aún en construcción...

---
## Herramientas usadas:
* Python 3
* Vscode
* Claude (Como apoyo en dudas)

---
## Características:
* creación de tablas en forma de diccionarios de python.
* Reconocimiento de comandos básicos como:
- `CREATE TABLE X`
- `INSERT INTO X Y`
- `SHOW DATABASE`
- `DELETE TABLE X`
- `DELETE DATABASE`
- `ADD COLUMNS` _en desarrollo_

## Métodos usados:
* Guardado de archivos de diccionario en json.
* Identificador de comandos usando recorrido por `index`en forma de `list`.
